# Inspired Article — Google Doc Template (for the marketing team)

Write each Inspired blog in its own Google Doc, using the labels below **exactly as written** (capital letters,
followed by a colon). Keep each label on its own line. Plain text is fine — no heading styles needed.

Everything in the doc goes into Shopify word for word. The tool does not rewrite or add text, so whatever you
write is exactly what appears on the site.

Lines marked *(optional)* can be left out. Everything else is required — if it is missing, the tool will
email you to say what needs adding.

---

## Images inside the article

To show an image inside a section (for example a product photo), paste it into the doc at the exact spot it
should appear. Optionally add a line directly under it:

```
IMAGE ALT: short description of the image
```

## Tips

- One blank line between paragraphs is fine; don't merge two paragraphs into one line.
- Keep the FORMAT tags exactly as shown, including the square brackets.
- If a section doesn't apply (e.g. no FAQ), leave that whole section out.
- Share the doc (or the folder it lives in) with the tool's service account email (Abbir will share this).
