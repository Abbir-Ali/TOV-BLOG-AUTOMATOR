# **TOV Blog Brief Guide for Marketing**

Blog briefs feed an automated Shopify publishing system. The system reads each brief as plain text. It picks up labels written in CAPS followed by a colon, and FORMAT markers written in square brackets. It ignores tables, HTML, markdown and formatting.

## **Which template to use**

Click the template you need. Google will ask you to make a copy, which saves a new brief to your own Drive. Rename your copy and fill it in. Never edit the master templates.

> * [**Inspired Post**](https://docs.google.com/document/d/14iFoCbjavK9VQYtI15svkU3cGMh4QIVusv5Ps9LYYzc/copy)**:** editorial articles, trend pieces, product roundups, how-tos and brand stories.  
> * [**Press Article**](https://docs.google.com/document/d/1-LHxRGLqDJ8N9MHoGv7HFgXfofP9fdRgGxLCmhwZsPM/copy)**:** when an outside publication covers TOV or one of our products.

## **The golden rules**

Write only after the colon on each label line, or on the line directly below it if the value is long.

Never write \[ADD LINK\], \[TBD\], XXX or anything in square brackets. Leave the field blank instead.

Plain text only: no bold, no bullet points, no markdown, no pasted tables.

Non-content (SEO notes, research sources, reminders) goes in Editor notes, never in the article body.

Never write FEATURED\_BLOG. That flag is set manually in Shopify.

Delete unused FORMAT sections from the body before submitting.

The CTA section is always required. Never delete it.

Lines starting with // are template guidance and are ignored by the system. Never start a field value with //.

## **Tag order matters**

The first tag becomes the blog card label, for example "Storage Ottomans". The first two tags become the tagline, for example "Storage Ottomans · Storage Benches". Put the most specific tag first and separate tags with commas.

## **Product cards**

For Inspired posts with product roundups, each product needs three things:

> 1. **A name line:** the product name, optionally followed by one badge at the end: New Arrival, Best Seller, Statement Length, Most Flexible or Final Sale.  
> 2. **A description paragraph** ending with: Best for \[who this is for\].  
> 3. **A matching line in PRODUCT LINKS:** Product Name — https\://tovfurniture.com/products/handle

The name in PRODUCT LINKS must match the card name exactly, without the badge.

## **Editor notes: what the system acts on**

Use these exact phrasings in the Editor notes field:

> * **Add a Design Services quote in the "\[Section Name\]" section** inserts the Design Box in that section.  
> * **Sidebar CTA should link to https\://… instead of Design Box** changes the sidebar button.  
> * **Sidebar CTA title should be "\[Title\]"** changes the sidebar title.  
> * **Confirm … before publishing** is added to the reviewer checklist.  
> * Research sources, SEO notes and internal context are kept for the editor and never published.

## **Common mistakes**

| Mistake | Fix |
| :---- | :---- |
| READ TIME or TAGS left blank | Fill both. The system stops without them. |
| \[ADD LINK HERE\] or TBD in a field | Leave the field blank instead. |
| SEO notes or sources in the body | Move them to Editor notes. |
| FORMAT line missing from a body section | Keep \[FORMAT: TYPE\_X\_NAME\] as the first line. |
| IN THIS ARTICLE doesn't match body headings | Copy and paste the headings exactly. |
| Product name differs between card and PRODUCT LINKS | Make them identical, minus the badge. |
| Description doesn't end with "Best for…" | Every product description must end with it. |
| Unused body sections left in | Delete any FORMAT section you didn't fill. |
| CTA section deleted | Always keep it. It is required. |
